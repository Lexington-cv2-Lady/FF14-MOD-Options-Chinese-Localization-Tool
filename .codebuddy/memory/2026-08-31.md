## v2.3.4：提取英文二级窗口 + 每批条数上限 1000

- 需求来源：用户要求「1. 提取英文」增加与「4. 恢复备份」一样的二级窗口（左侧 MOD 文件夹、右侧 group_*.json 可单独选择）；用户反馈几万条要翻译时每批上限 100 太少，问能否到 1000。
- 实现要点：
  1. 新增对话框 `IDD_EXTRACT_DIALOG`（rc 中直接用字面量 ID 1260-1265，cpp 顶部 `#ifndef` 兜底定义，防止 IDE 资源编辑器回滚 Resource.h 宏导致编译失败——这次 Resource.h 已加宏，rc 故意用字面量，双保险）。
  2. `ExtractDlgProc`：左侧 ListView（LVS_EX_CHECKBOXES，点击高亮即勾选、与恢复备份一致），显示所有含 group_*.json 的文件夹及文件数（带 "  (N)" 后缀）；右侧 ListBox（LBS_EXTENDEDSEL）显示当前高亮文件夹的 group_*.json，可多选；「全选」勾选所有文件夹；「提取选中」收集勾选文件夹文件（若当前高亮文件夹在右侧选中了文件则只取这些，否则取该文件夹全部）写入全局 `g_extractFiles` 后 EndDialog(IDOK)。
  3. `ExtractEnglish` 增加参数 `const std::vector<fs::path>* onlyFiles = nullptr`；非空时直接使用选中的文件集合，空则全量 ScanGroupFiles。主窗口 IDC_BTN_EXTRACT 先 DialogBox 弹选择窗口，返回非 IDOK 不执行提取。自动备份（zip）仍按选中文件夹全量执行，无影响。
  4. 每批条数上限 100→1000（两处：AITranslateBatch 的 clamp 和 IDC_AI_BATCH 的 EN_CHANGE 校验；rc 文案改为 1-1000）。推荐值：推理模型（大肥鱼 deepseek 等）200-500，快速模型 800-1000。
- **经验教训**：同一文件多处 replace_in_file 必须串行；`ListView_SetCheckState(...)` 宏展开后无大括号的 if/else 会报 C2181（无匹配 if 的非法 else），if/else 必须加大括号（RestoreDlgProc 原版也是带括号写法）。
